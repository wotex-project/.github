# Contributing

WoTEx is a family of Elixir libraries being prepared for public release. Each
repository takes fixes to code and documentation through pull requests and
follows the OTP conventions described in its readme. Scope and the marks are
maintainer-controlled, so open an issue before spending time on anything beyond
a focused fix.

Use issues for reproducible bugs and documentation errors. Report vulnerabilities
as described in [SECURITY.md](SECURITY.md), never in a public issue. Everything
else goes to [hello@wotex.io](mailto:hello@wotex.io).

Each repository documents its own toolchain and checks in its readme. Run them
before opening a pull request, keep a pull request to one change, and say what
was verified.

By submitting a contribution you agree that it may be distributed under the
license of the repository it targets. Do not submit material you are not
authorized to license. Keep discussion on the work.
